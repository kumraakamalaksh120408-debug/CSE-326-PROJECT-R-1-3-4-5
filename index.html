About this project

CaseDesk is a front-end academic project showing how courts and citizens could manage cases online. It uses only HTML, CSS and JavaScript.

Concepts used

  • HTML: semantic tags, forms, tables, lists, SVG, audio, video, iframe, SEO meta tags.
  • CSS: variables, Flexbox, Grid, box model, pseudo-classes, transitions, animations, media queries.
  • JavaScript: variables, data types, operators, strings, numbers, conditions, functions, scope, arrays, objects.

Academic demonstration only. Not an official court website; no legal advice is given.

Multimedia and embedded information

Audio, video and iframe elements. The files are stored in the project folder, so they work without internet.
