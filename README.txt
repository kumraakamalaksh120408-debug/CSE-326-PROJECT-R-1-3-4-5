CaseDesk - Online Legal Case Management System (CSE326 Internet Programming)

FILES
- index.html          full website (one page, sections linked from the menu)
- unstyled.html       same page without the stylesheet (for "HTML only" screenshots)
- css/style.css       all styling: variables, selectors, box model, positioning,
                      Flexbox, Grid, pseudo-classes/elements, transitions,
                      animations, media queries
- js/main.js          all JavaScript: data (arrays/objects), functions, search,
                      filters, form validation, tracking, login demo, theme toggle
- img/                logo and SVG illustrations
- media/              audio (reminder.mp3), video (walkthrough.mp4), poster.png
- court-timings.html, help-desk.html   small pages shown inside the iframes
- SYLLABUS-CHECKLIST.txt   where each syllabus topic is used

HOW TO RUN
Extract the ZIP and double-click index.html. No internet connection is needed:
every image, audio and video file is inside the folder.

NOTE
All case records, judges and advocates are fictional. This is an academic
demonstration, not an official court website, and gives no legal advice.
The login is a front-end demo only (no server): any valid email and a password
of 8+ characters containing a number is accepted.
